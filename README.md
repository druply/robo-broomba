# robo-broomba
this is a project for a robot that can navigate the inside of a house.

# How to run
Run the following commands:
sh build.sh
cd build
cmake ..
make
./robot-broomba

## Explanation:
The "build.sh" script creates two folder "gen" and "build", it also generates code needed for the program to run.
then you go into the build folder and run cmake .., this builds the project.
finally "make" compiles the project.
and "./robot-broomba" runs the project.
